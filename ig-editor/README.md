# IG Frame Editor
Pegá un link de Instagram, navegá frame a frame, marcá inicio/fin y descargá el recorte en MP4.

```bash
pip install -r requirements.txt   # requiere también ffmpeg instalado
python app.py                     # abrir http://localhost:5000
```
Si Instagram pide login (posts privados o rate-limit), exportá tus cookies en formato Netscape a `cookies.txt` en esta carpeta.
